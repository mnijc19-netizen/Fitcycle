# 📜 FITCYCLE 核心架构与多系统扩展底层宪法
# (Fitcycle Core Architecture Constitution & Universal Protocol)

> **宪法宗旨：** 本宪法是 Fitcycle 系统开发的最高设计与工程准则。无论未来扩展多少种新皮肤（赛博朋克、中世纪、机甲等）、接入多少类全新运动类型（跑步机有氧、椭圆机、爬楼机、徒手自重、HIIT 等）、或新增何种竞技机制，**全系统代码与数据模型必须无条件遵循本宪法，确保架构永不臃肿、数据永不混乱、规则永不割裂。**

## 🏛️ 第一章：系统架构与数据单一事实源公理 (Single Source of Truth)

### 第 1.1 条【零业务侵入与纯配置字典隔离原则】
1. **核心计算引擎（Core Engine）** 严禁包含任何特定皮肤（如 CS2、Valorant）的硬编码字面量或分支判断（严禁出现 `if (skin === 'cs')` 计算不同的分数）。
2. **所有皮肤必须为纯数据驱动的“视效与文本映射字典 (Skin Localization Schema)”**。添加任何全新皮肤，仅需提供一个独立的 JSON / 对象配置表，业务代码无需修改一行。
3. 任何皮肤配置字典必须且仅须实现以下 **5 大标准插槽 (Standard Slots)**：
   *   `Tiers`: 战力等级名称与徽标映射表（Tier 1 ~ 7）；
   *   `Badges`: 勋章称号与描述本地化字典；
   *   `Audios`: 提示音效映射表（C4滴答、特工音效、清脆哨音）；
   *   `Tokens`: 战术 HUD 视觉组件库（弹药计数器、血条、高能护甲）；
   *   `Themes`: Tailwind 语义化调色盘（Primary, Accent, Glow）。

## 🏃 第二章：多运动类型做工等效归一化公理 (Universal Work & METs Conversion Theorem)

> **背景：** 健身不仅是力量举或抗阻。未来将纳入跑步机慢跑、坡度快走、划船机、动感单车、徒手自重等多样化运动。本章定义如何将所有运动科学折算为统一的 **做工等效吨位 (Equivalent Tonnage)** 与 **训练冲量 (TRIMP / Impulse Points)**。

### 第 2.1 条【国际运动代谢当量 (METs) 能量等效模型】
根据国际运动医学公认的 **METs（Metabolic Equivalent of Task 代谢当量）** 与能量做工消耗，设立统一转换公式：

$$\text{等效抗阻做工吨位 (Equivalent Tonnage, kg)} = \text{METs 系数} \times \text{持续时间 (分钟)} \times \text{体重 (kg)} \times 0.65$$

### 第 2.2 条【各运动大类标准归一化转换矩阵】

| 运动类型 (Category) | 核心计量输入参数 | 生物学 METs 系数 | 等效做工折算规则 (用于总吨位与排位分) |
| :--- | :--- | :---: | :--- |
| **A. 传统抗阻器械 (Resistance)** | 重量 (kg) × 次数 × 组数 | 6.0 ~ 8.0 | **实测真实吨位** = $\sum(\text{重量} \times \text{次数})$ |
| **B. 跑步机/户外跑步 (Running)** | 距离 (km)、配速 (min/km)、心率 | 9.8 ~ 11.5 | **等效吨位** = $\text{距离(km)} \times \text{体重(kg)} \times 8.5$（如 70kg 跑 5km 相当于 2,975kg 机械做工） |
| **C. 坡度快走/椭圆机 (Incline Walk)** | 坡度 (%)、速度、时间 (min) | 6.0 ~ 7.5 | **等效吨位** = $\text{时间(min)} \times \text{体重(kg)} \times (1 + \text{坡度}\%) \times 0.7$ |
| **D. 划船机/动感单车 (Rowing/Bike)** | 卡路里 (kcal)、平均瓦特 (Watts) | 7.0 ~ 8.5 | **等效吨位** = $\text{消耗大卡 (kcal)} \times 12.5$（如消耗 300kcal 相当于 3,750kg 做工） |
| **E. 徒手自重/引体俯卧撑 (Calisthenics)** | 动作类型、次数、组数 | 5.0 ~ 7.0 | **等效重量** = $\text{体重} \times \text{动作负重比}$（俯卧撑 0.65x 自重，引体向上 1.0x 自重） |
| **F. 瑜伽/动态拉伸 (Mobility & Yoga)** | 持续时长 (min) | 2.5 ~ 3.5 | 不计入机械大负荷吨位，**全额计入出勤连胜分与超量恢复健康加分** |

## 📈 第三章：综合战力积分 (FPS) 与电竞排位晋级公理

### 第 3.1 条【战力积分计算恒等式】
用户综合战力积分（Fitcycle Power Score，FPS，0 ~ 3000+）由 4 大不可分割的维度构成：
1. **自律周频分 (40%)**：只要规律出勤，无论做工大小均能稳定获取基础分；
2. **总累计做工吨位 (30%)**：全品类运动（抗阻真实吨位 + 有氧等效吨位）终身累加；
3. **相对能力/围度蜕变分 (20%)**：三大项体重比突破，或手臂/胸围/腰围黄金比例改善；
4. **高质量单场表现分 (10%)**：S/A 级深度做工与渐进超负荷增量。

### 第 3.2 条【全皮肤 7 大段位绝对映射准则】
无论未来新增任何皮肤，必须严格对齐以下 7 阶分数区间：

```
[Tier 1: 0~299]   -> 新兵 / 白银一 (Silver I) / 黑铁 (Iron)
[Tier 2: 300~699] -> 进阶 / 白银精英 (Silver Elite) / 青铜 (Bronze)
[Tier 3: 700~1199] -> 中坚 / 黄金新星 (Gold Nova) / 白银-黄金 (Silver-Gold)
[Tier 4: 1200~1799]-> 雕刻家 / 大师级守卫 AK (MG) / 白金-钻石 (Plat-Dia)
[Tier 5: 1800~2399]-> 资深健力士 / 大老鹰-小地球 (Eagle) / 超凡入圣 (Ascendant)
[Tier 6: 2400~2899]-> 传奇泰坦 / 大地球特工 (Global Elite) / 神话 (Immortal)
[Tier 7: 2900+]   -> 巅峰神话 / 完美魔王 S / 赋能战神 (Radiant) -> 开启无上限巅峰天梯
```

## 🧬 第四章：生理学怠惰衰减与心理学复苏戒律

### 第 4.1 条【科学超量恢复免责法则】
*   **0 ～ 72 小时内严禁扣分**：推拉腿分化中的必要休息与肌原纤维合成受宪法保护，扣分为违宪行为。

### 第 4.2 条【阶梯去适应衰减律】
*   **第 4 天（72～96h）**：`-5 分 / 日`（神经生锈轻度预警）；
*   **第 5～7 天（96～168h）**：`-15 分 / 日`（肌糖原消退中度催练）；
*   **第 7 天以上（>168h）**：`-25 分 / 日`（肌肉去适应重度危机，衰减至大段位保底分即止）。

### 第 4.3 条【破冰首战 1.5 倍超量复苏法则 (Redemption Law)】
*   断练 5 天以上回归的首场正式训练（达到 B 级及以上），强制触发 **`150% 战力复苏爆发加成`**，瞬间止血并补回流失分数，彻底杜绝习得性无助与流失。

### 第 4.4 条【战术减载周与伤病休养免战盾牌 (Tactical Deload & Injury Shield)】
*   **周期化减载科学**：运动生理学要求每 6～8 周高强度训练后进行 1 周主动减载（Deload），或因伤病流感需要休养 1～2 周；
*   **战术休整申报**：用户每 60 天可申报开启为期 **7～14 天的战术休整期**。期间战力怠惰衰减强制冻结（0 扣分），轻度拉伸或活动仍正常计入出勤，彻底消除科学减载期间掉分的心理顾虑。

## 📐 第六章：身体形体围度追踪数据协议 (Anthropometric Schema)

### 第 6.1 条【核心围度数据标准】
所有形体测量数据以厘米 (cm) 为法定基准单位，包含 5 大不可替代解剖学生理点：
1. `arm`: 上臂最大围度（二头/三头肌峰）
2. `chest`: 胸部水平围度（乳头水平线）
3. `waist`: 腹部腰围（肚脐上方 2cm 核心线）
4. `thigh`: 大腿中段围度（股四头肌隆起处）
5. `weight`: 晨起净体重 (kg)

### 第 6.2 条【形体蜕变指数 (Body Recomposition Index)】
系统自动计算 $\text{V字倒三角比例} = \frac{\text{胸围 (Chest)}}{\text{腰围 (Waist)}}$。当腰围下降且胸围/臂围上升时，强制触发健美塑形专属加分与勋章解锁。

### 第 6.3 条【形体测量防刷分与生理学生长节律公理 (Anti-Exploit & Biological Rate of Growth Law)】
1. **7 天基础测绘加分冷却法则 (7-Day Cooldown)**：
   * 人体肌肉蛋白质合成与肌纤维肥大属于周/月级生理进程。基础记录奖励分（+20 FPS）设定 **7 天冷却周期**；
   * 同一自然周内可无限次更新修正围度数据，但**单周内最多仅计入 1 次基础建档分**，彻底杜绝单日频繁录入刷分漏洞。
2. **实质性形体蜕变里程碑阶梯奖励 (True Growth Delta Rewards)**：
   * 只有当围度产生真实的**跨周期正向改善**（如臂围净增 $\ge 1.0\text{cm}$、胸围净增 $\ge 2.0\text{cm}$、腰围收紧 $\ge 2.0\text{cm}$）时，才触发对应档位的里程碑成就加分并解锁专属勋章。
3. **生理学合理性防伪过滤 (Biological Plausibility Filter)**：
   * 严禁无生理依据的单日异常剧烈波动刷分，确保天梯榜单与荣誉徽章的绝对真实性与公信力。

### 第 6.4 条【人类生理极限与手滑离群值拦截公理 (Fat-Finger Anomaly Clamp)】
*   单组重量 $\ge 350\text{kg}$、单组次数 $\ge 100\text{次}$、或单次围度增量 $\ge 10\text{cm}$ 自动判定为手滑录入异常，进行友好确认拦截，防止手滑污染终身 PR 荣誉榜。
